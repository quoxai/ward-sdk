# Contributing

Contributions are welcome and are handled on a best-effort basis, with no
service-level agreement on review time.

## Licence

This project is licensed under Apache-2.0. By submitting a contribution you
agree that it is licensed under the same terms (inbound equals outbound).

## Workflow

1. Open an issue first for anything larger than a small fix.
2. Fork the repository and branch from `main`.
3. Run `npm install` and `npm test` before opening a pull request.
4. Keep changes focused and add tests for new behaviour.

## Security

Do not report vulnerabilities in public issues. See [SECURITY.md](./SECURITY.md).

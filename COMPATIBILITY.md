# Compatibility

`@quox/ward` targets QuoxCORE 4.x.

## Versioning intent

This package follows semantic versioning in intent. Breaking changes to the
public API or the on-disk format bump the major version. New, backwards
compatible capability bumps the minor version. Fixes bump the patch version.
The WARD specification version supported is stated in the README and CHANGELOG.

## Support

Compatibility with other QuoxCORE major versions is not guaranteed. Support is
best-effort and carries no service-level agreement.
